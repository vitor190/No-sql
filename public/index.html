Chat em tempo real sobre o GigaSpaces

Cada mensagem deste chat é uma tupla guardada no Space do GigaSpaces, um banco de dados em memória do paradigma de armazenamento de tuplas.

  • Ao entrar, o servidor grava uma tupla Usuario no Space (write).
  • Para mostrar o tempo real, abra uma janela anônima e entre com outro nome.

        3. Como uma mensagem vira tupla

        Mensagem( id="msg-…", salaId="geral", autorId="ana", texto="Oi!", enviadaEm=1731770000000, editada=false )
        • salaId é a routing property: decide em qual das 2 partições a tupla fica. Todas as mensagens de uma sala ficam juntas, então abrir a sala consulta uma partição só.
        • Abrir a sala é uma consulta por template: só salaId é preenchido, e os outros campos funcionam como coringa.

        4. E o "tempo real"?

        A tela pergunta ao Space a cada 1 segundo se há mensagens novas (polling). A API REST do GigaSpaces não tem notify (ele existe nas APIs Java e .NET). Marque "mostrar leituras automáticas" no painel da direita para ver essas leituras.
